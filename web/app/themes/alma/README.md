# Alma theme

The application half of Alma v8: an Acorn (Laravel) container inside a WordPress theme.

- Code: `app/` (modules in `app/Domains`, blocks in `app/Blocks`), `config/`, `routes/`
- Views: `resources/views` (Blade; Livewire single-file components in `components/<module>/`)
- Pages: `patterns/`
- Tests: `tests/` (`composer check` runs everything CI runs)
- Docs: [`docs/`](docs/README.md)

See the repository [README](../../../../README.md) and [CLAUDE.md](../../../../CLAUDE.md).
